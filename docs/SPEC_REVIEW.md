# Сверка первоисточников — 23.09.2026

[Официальное ТЗ](https://docs.google.com/document/d/1PUDYCg2OC_wfBk4rq5673yc1qsmo8O5_pwxjm483omU/edit)
прочитано через `export?format=txt`, включая русскую, казахскую и английскую версии.
Локальные копии находятся в игнорируемом `data/research/`.

## Семь обязательных пунктов именно официального ТЗ

| Требование | Текущий результат |
|---|---|
| Распознавание речи | Автономный CLI STT, пока без web-конвейера |
| Понимание русского | Первый речевой прогон; качество на корпусе не измерено |
| Понимание казахского | Не проверено |
| Понимание смешанной речи | Не проверено |
| Поручения с ответственным и сроком | Не реализовано |
| Диаризация с привязкой поручения к человеку | CLI диаризации работает; привязка к человеку/поручению не реализована |
| Экспорт PDF/DOCX | Не реализовано |

Входы включают запись/live и подключение участником к Teams/Zoom/Meet, но отдельный
обязательный минимум не перечисляет конференц-бота. План законченного пути загрузки
записи сохраняется, вопрос допуска без бота остаётся открытым.
Облачная передача аудио/текста запрещена; синтетические записи разрешены, реальные
записи для демонстрации должны быть обезличены. Напоминания описаны в сценарии,
но не выделены в обязательный минимум — не объявляем их реализованными.

## Примеры

Прочитаны [пример 1](https://docs.google.com/document/d/1umHtiQ4og9i2_8m6fSBulffN5K-0q_pt/edit)
и [пример 2](https://docs.google.com/document/d/142maSHWfO83yFB4mNtZ8AMJiI_y0NBJb/edit).
Из них следуют полезные кейсы для будущей проверки:

- согласованный срок меняется в ходе обсуждения;
- исполнитель может не быть говорящим и даже участником разговора;
- итоговое повторение нельзя считать новой задачей;
- срок может отсутствовать или зависеть от события;
- поручение организации нельзя без основания приписывать конкретному человеку.

Готовые саммари не подавались в STT и не являются входом модели извлечения.
Числа качества по этим примерам не рассчитаны; текстовые документы сами по себе
не подтверждают качество распознавания или диаризации.
