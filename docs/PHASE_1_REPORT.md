# Фаза 1: локальный STT — 23.09.2026

Фаза выполнена частично. Whisper и community-1 запускаются локально на CPU;
казахская и смешанная речь ещё не проверены. UI и health readiness по-прежнему
отражают неготовность MVP.

## Что сделано

- Прочитаны официальное ТЗ и два примера: [сверка](SPEC_REVIEW.md).
- Через winget установлен Gyan.FFmpeg 9.0.2, проверены ffmpeg и ffprobe.
- В optional-профиле `stt` закреплены faster-whisper 1.2.1, CTranslate2 4.8.2,
  PyAV 18.1.0 и psutil 7.2.2; полный набор версий — `uv.lock`.
- Скачана multilingual-модель `Systran/faster-whisper-small` (MIT), revision
  `536b0662742c02347bc0e980a01041f333bce120`. Размер model.bin — 483 546 902 байта.
  [Manifest с размерами и SHA-256](stt-model-manifest.json) фиксирует все пять файлов.
- Добавлен CLI с CPU int8, четырьмя потоками, VAD, таймкодами слов и сегментов.
  Спикеры остаются null, поскольку диаризация ещё не выполняется.
- Исходные записи не изменялись. Результаты находятся только в игнорируемом `data/`.

## Реальные измерения

Windows 10 Pro, Python 3.11.9, CPU; GPU не использован.
Первую запись пользователь явно разрешил обработать локально.

| Вход | Длительность аудио | Загрузка модели | Inference | Всего | Peak working set процесса |
|---|---:|---:|---:|---:|---:|
| Первые 60 секунд записи №1 | 60 с | 1.236 с | 17.380 с | 18.616 с | Не измерялся |
| Полная запись №1 | 274.25 с | 1.188 с | 101.970 с | 103.158 с | 719.8 МиБ |
| Синтетическая русская речь Windows Irina | 17.312 с | 1.121 с | 5.281 с | 6.401 с | 719.6 МиБ |

Peak working set — показатель одного процесса Windows, не суммарная память системы.
Время не включает подготовительную загрузку весов и импорт Python-библиотек.
Синтетический тест содержит один голос и не проверяет диаризацию.
В полной записи получено 45 сегментов; все интервалы положительные и укладываются
в длительность записи. В синтетическом тесте все 22 слова совпали с эталоном после
приведения к нижнему регистру, замены «ё» на «е» и удаления пунктуации.
Это проверка одного простого образца, а не оценка качества на корпусе.
Модель определила русский язык во всех трёх прогонах. Это не доказывает отсутствие
казахских слов и не подтверждает качество KK/mixed.
WER/CER реального совещания и DER не измерены: нужна проверенная аудиоразметка.

## Повторение

Из корня проекта, первоначальная подготовка с интернетом:

```powershell
winget install --id Gyan.FFmpeg --exact --source winget
uv sync --frozen --extra stt
.\.venv\Scripts\python.exe scripts/prepare_stt.py
```

После установки FFmpeg открыть новый терминал для обновления PATH.
Скрипт подготовки скачивает только фиксированный revision публичных весов,
не принимает записи на вход. Последующие прогоны используют локальный путь:

```powershell
.\.venv\Scripts\python.exe -m autoprotocol.pipeline.transcribe "C:\Users\AdminUCCs3\Desktop\projects\Совещание №1.mp3" --output data/smoke/meeting-1-full-stt.json
```

Синтетический тест (требует локальный голос Microsoft Irina Desktop):

```powershell
.\scripts\synthesize_smoke.ps1
.\.venv\Scripts\python.exe -m autoprotocol.pipeline.transcribe data/smoke/ru.wav --output data/smoke/ru-stt.json
```

CLI загружает только локальные веса, включает HF_HUB_OFFLINE и отключает телеметрию
Hugging Face. Аудио/текст не отправляются в облачные API. Полный тест с системно
отключённой внешней сетью и мониторингом трафика ещё не выполнен.
С обычным `uv sync` дополнительные зависимости могут удалиться — для STT всегда
использовать `--extra stt`. Обычный web-запуск не требует STT.

## Проверки и оставшиеся зависимости

- `ruff check src tests scripts` и `ruff format --check src tests scripts`.
- `python -m pytest -q`: 6 тестов пройдены; одно прежнее предупреждение Starlette/httpx.
- Проверки отсутствующего аудио/модели завершаются до импорта inference-библиотек
  и не вызывают автоскачивание.
- Условия community-1 приняты пользователем, вход выполнен через OAuth device flow.
  Секрет хранится механизмом Hugging Face вне проекта, в git не добавляется.
- Нужны отдельно проверенные записи KK/mixed и разметка говорящих.
- LLM, поручения, web-загрузка и экспорт в этой фазе не реализовывались.

## Диаризация community-1

Веса CC-BY-4.0: `pyannote/speaker-diarization-community-1`, revision
`3533c8cf8e369892e6b79ff1bf80f7b0286a54ee`.
Атрибуция: pyannote и авторы, перечисленные в model card; исходные README сохранены
в каталоге весов. [Manifest с SHA-256](diarization-model-manifest.json).

Профиль `diarization` в uv.lock: pyannote.audio 4.0.7, torch 2.14.0,
torchaudio 2.11.0, torchcodec 0.16.0. Проверен путь передачи waveform напрямую:
аудио предварительно нормализуется FFmpeg, PCM читается стандартной библиотекой.
Совместимость остальных путей torchaudio/torchcodec не заявляется.

Первый прогон: 60 секунд записи №1, 3 автоматически выделенных говорящих,
2.299 с загрузки + 39.966 с inference = 42.265 с; peak working set 2350.3 МиБ.
Полная запись №1 (274.25 с): 4 автоматически выделенных говорящих,
3.839 с загрузки + 223.448 с inference = 227.287 с; peak working set 2346.4 МиБ.
Имена участников неизвестны; DER и правильное число говорящих требуют ручной разметки.
В результатах сохраняются обычные интервалы с перекрытиями и exclusive-интервалы.
Метки независимых прогонов не следует считать одинаковыми идентичностями.

```powershell
uv sync --frozen --extra stt --extra diarization
.\.venv\Scripts\python.exe scripts/prepare_diarization.py
ffmpeg -i "C:\Users\AdminUCCs3\Desktop\projects\Совещание №1.mp3" -ac 1 -ar 16000 -c:a pcm_s16le data/smoke/meeting-1-full.wav
.\.venv\Scripts\python.exe -m autoprotocol.pipeline.diarize data/smoke/meeting-1-full.wav --output data/smoke/meeting-1-full-diarization.json
```

Подготовительный скрипт использует локальный вход Hugging Face. Обычный inference
использует только локальную папку; HF_HUB_OFFLINE=1, HF_HUB_DISABLE_TELEMETRY=1,
PYANNOTE_METRICS_ENABLED=0 устанавливаются до импорта ML-библиотек.
CLI ограничен 10 минутами аудио для исследовательского прогона; это не лимит
будущего продукта. Слияние STT и диаризации, имена и web-интерфейс ещё не реализованы.

В первом прогоне было предупреждение PyTorch о дисперсии короткого фрагмента;
оно не остановило выполнение, качество спорных участков нужно проверять.
Кеш matplotlib перенесён в `data/cache/`, чтобы не требовать записи в профиль
пользователя при ограниченных правах. Проверка без внешней сети на уровне ОС
остаётся отдельным незавершённым пунктом приёмки.
