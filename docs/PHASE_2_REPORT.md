# Web-загрузка и отдельный worker

Реализована рабочая часть фазы 2: загрузка, встречи, очередь и просмотр транскрипта.
Participant/ActionItem/SummaryItem/Revision и редактор результатов ещё не созданы;
поэтому фазу в полном объёме и весь MVP не объявляем завершёнными.

## Использование

После подготовки ML-моделей выполнить `scripts/run.ps1`, открыть localhost:8000.
Ввести название, необязательную дату, IANA timezone, выбрать файл и подтвердить
право обработки. После загрузки можно закрыть страницу: worker продолжит работу.
В списке встреч отображаются этап или ошибка. Готовый результат содержит
аудиоплеер, текст, метки говорящих и спорные места; кнопка таймкода запускает аудио
с соответствующего момента. Имена пока не назначаются, исправления не сохраняются.

Исходный дизайн JazAI сохранён; добавлены форма, список встреч и транскрипт.
Полный визуальный и интерактивный браузерный прогон не выполнен: браузеры
недоступны инструменту этой сессии. Проверены HTML/API, синтаксис JavaScript и backend.

## API и ограничения

- `POST /api/meetings`: тело — байты файла, `Content-Type: application/octet-stream`;
  query: title, consent=true, timezone, occurred_on (YYYY-MM-DD, необязателен).
  Возвращает 202 и id. Отказ в согласии/невалидная дата/зона — 422.
- Необязательный заголовок `Idempotency-Key` (UUID): повтор возвращает ту же встречу.
  Ключ относится к одной логической загрузке; повторный body не заменяет оригинал.
- Лимит байтов проверяется потоково, в том числе без Content-Length; превышение — 413.
  Проверка ffprobe подтверждает аудиодорожку и длительность, а не доверяет имени/MIME.
- `GET /api/meetings` — последние 100 встреч; `GET /api/meetings/{id}` — статус.
- `/result` — объединённый JSON; `/audio` — PCM WAV с HTTP Range (206).
  До готовности оба возвращают 409. Неизвестная встреча — 404.
- Поддерживаемые контейнеры ограничены demuxer-списком MP3/WAV/MOV/Matroska/OGG/FLAC/AAC;
  действительная декодируемость проверяется при чтении. Плейлисты и сетевые протоколы
  FFmpeg запрещены. Видео пока не проверялось настоящим примером.
- Предел длительности равен min(настройка, 10 минут). Увеличение настройки не снимает
  ограничение исследовательского модуля диаризации. Настройка размера по умолчанию 250 МБ.
- Один локальный пользователь, только loopback, без авторизации. Проверяются Host
  и Origin загрузки. Для совместного доступа нужны отдельные защита и авторизация.

## Данные и восстановление

Миграция schema_version=2 добавляет `meetings` и `jobs`, сохраняя прежнюю БД.
Meeting хранит метаданные, подтверждение права обработки, SHA-256 оригинала,
статус, этап, безопасную ошибку и пути локальных артефактов. Слова/сегменты пока
хранятся в JSON. Имена файлов генерируются из UUID; исходное имя не используется как путь.

Захват задачи транзакционный (`BEGIN IMMEDIATE`). Допускается одна активная lease
на всю очередь; два worker не захватывают две тяжёлые задачи одновременно.
Heartbeat — каждые 10 секунд, lease — 60 секунд. После истечения lease разрешено
до двух попыток всего, затем failed. Владелец предыдущей lease не может опубликовать
результат или продлить чужое задание. Таймаут этапа — 1800 секунд, настраивается.
Обычная ошибка модели сразу приводит к failed; автоматически повторяется именно
прерванная задача. Кнопка ручного повтора пока не добавлена.

Каждая попытка создаёт собственный каталог; успешные пути публикуются транзакцией
в SQLite лишь после завершения всех этапов. Частичные артефакты не выдаются как ready.
После аварии попытка начинается заново, без возобновления промежуточного inference.
Старые файлы попыток пока остаются на диске; политика очистки — последующая работа.
Если ОС принудительно убила родителя, оставшийся ML-процесс может ещё потреблять
ресурсы; lease защищает публикацию результата, а не является блокировкой CPU на уровне ОС.

`ready` означает только готовность чернового транскрипта, stage=`transcript_ready`.
Не реализованные поручения/саммари/экспорт не маскируются этим статусом.
`/health/ready` остаётся 503 для полного протокола; `/health/live` — 200.

## Проверки

- Реальный HTTP POST первой минуты записи №1 → queued → processing → ready.
  7 исходных сегментов, 119 слов → 10 фрагментов, 2 слова без говорящего.
- Настоящий FFmpeg → Whisper → community-1 → align, без подготовленного ответа.
- Получение JSON — 200; Range `bytes=0-99` — 206 и ровно 100 байтов WAV.
- Повреждённое содержимое — 422, запись не поставлена в очередь.
- Сохранённая встреча доступна новому серверу после перезапуска.
- Синтетическая русская запись также прошла API и worker до ready.
- Unit/integration: 39 тестов (очередь, просроченные lease, защита от старого worker,
  повтор без дублей, отсутствующие модели, лимиты, метаданные, остановка процессов,
  STT/диаризация/объединение и миграция). Одно предупреждение Starlette/httpx.
- Ruff и `node --check src/autoprotocol/web/static/app.js`.
- Проверен отказ общего запуска при занятом 8000: код выхода 1, дочерний worker
  не остаётся работать. Тестовый сервер запущен на 8011 без остановки чужого процесса.

Полная offline-проверка с отключением внешней сети, DER/WER корпуса и браузерное
взаимодействие остаются невыполненными. Реальные записи/результаты/веса/токены
в git не включены.
