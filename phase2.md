### Фаза 2. Данные, загрузка и очередь

Создать версионированные миграции Meeting, Participant, Segment, ActionItem,
SummaryItem, Revision и Job; контракты API см. ARCHITECTURE.md.
Добавить загрузку с подтверждением права обработки, потоковым лимитом байтов,
проверкой ffprobe и длительности; хранить файл под UUID вне web/static.
Не доверять имени, расширению и MIME клиента; запускать ffmpeg без shell.
Дата встречи может отсутствовать, часовой пояс проверяется по IANA.
Реализовать транзакционный захват очереди одним worker, heartbeat, lease,
ограниченные повторы, восстановление и сохранение ошибки без транскрипта в логах.

Приёмка: queued → processing → ready/failed; повторный старт не дублирует задачу;
превышение лимита отклоняется; сбой процесса не теряет запись и не оставляет её
навсегда в processing. Нереализованные этапы не переводят встречу в ready.
