# Граница будущего конвейера

`transcribe.py` — работающий автономный CPU-прогон STT с локальными весами,
таймкодами и JSON-артефактом. Worker вызывает его отдельным процессом.
`diarize.py` — автономный CPU-прогон community-1 с локальными весами на mono
16 kHz PCM16 WAV (до 10 минут), возвращающий обычные и exclusive-интервалы.
Имена участников не определяет. Веса загружаются только на подготовительном этапе.
`align.py` объединяет результаты STT и диаризации по словам, сохраняет источники
и пометки неоднозначности; выводит JSON и необязательный TXT для проверки.
Подготовка аудио и оркестрация реализованы в `worker.py`/`media.py`.
Адаптеры `extraction`, `validation` поручений и `export` пока не реализованы.

HTTP API сохраняет файл и задачу; отдельный worker обрабатывает очередь SQLite.
Нельзя выполнять длительный ML inference в FastAPI BackgroundTasks.
Один worker последовательно загружает/освобождает модели, ограничивая RAM.
Контракты и обработка сбоев описаны в `docs/ARCHITECTURE.md`.
